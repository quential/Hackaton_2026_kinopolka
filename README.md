### От себя

- Подбор фильма под настроение через небольшой тест.
- В тесте есть вопросы про компанию, погоду, настроение и количество свободного времени.
- Варианты ответов сопровождаются подходящими эмодзи.
- Результаты теста считаются по жанрам, рейтингу, возрастному ограничению и длительности фильма.
- Для каждого ответа подбираются подходящие фильмы из общего массива, поэтому подборка работает и после добавления новых фильмов.
- Для каждого жанра сделаны отдельные страницы с заголовком, описанием и фильмами.
- На жанровых страницах фильмы сортируются по рейтингу.
- В шапке сохранена единая навигация на всех экранах.
- Добавлены переключатель светлой и тёмной темы с иконками солнца и луны.
- Добавлен логотип и название «Кинополка».
- Добавлен экран приветствия перед началом работы с сайтом.
- В модальном окне фильма есть кнопка «Смотреть», которая открывает ссылку на Rutube.
- Для каталога подготовлено 200 фильмов, включая 150 дополнительных.
- Постеры хранятся локально в проекте, поэтому каталог не зависит от загрузки картинок с внешних сайтов.
- Для фильмов добавлены ссылки на Rutube: прямые ссылки на видео и точные поисковые ссылки по названию и году, если надёжного полного видео не нашлось.
- Добавлены уведомления после сохранения фильма, удаления из списка, добавления отзыва и открытия Rutube.
- Добавлена маршрутизация через React Router: у главного экрана, каталога, сохранённых фильмов, теста и жанров есть отдельные URL.
- Интерфейс сделан в минималистичном стиле с эффектом liquid glass и визуальной логикой Apple TV.


## Как запустить проект

Открой терминал в папке `var` и выполни:

```bash
npm install && npm run dev
```

После этого Vite покажет локальный адрес сайта. Обычно это адрес вроде `http://localhost:5173`.

Для проверки production-сборки можно выполнить:

```bash
npm run lint
npm run build
```

Для просмотра уже собранной версии используется:

```bash
npm run preview
```

## Как пользоваться сайтом

### Первый экран

После запуска открывается приветственный экран. Нажми кнопку продолжения, чтобы перейти к подборкам.

В шапке есть логотип «Кинополка», переходы в подборки, каталог и список «Посмотреть позже». Справа находится переключатель темы. При нажатии меняется и тема, и иконка солнца или луны.

В блоке «Выбор редакции» можно пролистывать карточки фильмов горизонтально. На карточке видны постер, название, год, жанр и рейтинг. Кнопка «Обновить подборку» без перезагрузки выбирает другую группу фильмов.

Если нажать на карточку, откроется подробное окно фильма. В нём можно посмотреть описание, длительность, режиссёра и актёров, сохранить фильм на потом или нажать «Смотреть».

### Подбор по настроению

В блоке «Подобрать фильм под настроение» нажми «Подобрать».

Дальше появится тест. На каждом шаге выбери один вариант ответа и нажми «Дальше». В конце сайт покажет фильмы, которые лучше всего подходят под выбранные ответы.

Если нужно пройти тест заново, нажми «Пройти заново». Вернуться на главный экран можно кнопкой «К подборкам» или через пункт «Подборки» в шапке.

### Жанровые страницы

В блоке «Если хочется чего-то другого» выбери жанр: драму, комедию, фантастику или триллер.

Откроется отдельная страница с названием жанра, коротким описанием и всеми подходящими фильмами. Фильмы там отсортированы по рейтингу. Любую карточку можно открыть, сохранить или отправить на Rutube.

### Каталог

В разделе «Каталог» можно:

- выбрать жанр;
- найти фильм по названию;
- отсортировать список по рейтингу, году или названию;
- открыть подробности фильма;
- добавить фильм в «Посмотреть позже».

Поиск работает по русскому названию, которое показывается в карточке.

У экранов есть отдельные адреса: `/`, `/catalog`, `/saved`, `/mood` и `/genre/drama`, `/genre/comedy`, `/genre/sci-fi` или `/genre/thriller`. Поэтому нужную страницу можно открыть напрямую или отправить ссылкой.

### Посмотреть позже

В «Посмотреть позже» попадают фильмы, которые были сохранены кнопкой с закладкой. Чтобы убрать фильм, нажми на эту же кнопку ещё раз.

Список хранится в браузере пользователя через `localStorage`, поэтому он сохраняется после обновления страницы. Если очистить данные сайта в браузере, список тоже очистится.

### Отзывы и оценки

Открой фильм и нажми кнопку «Оценки». Панель с отзывами плавно раскроется внутри модального окна.

Чтобы оставить свой отзыв, наведи курсор на звёзды и выбери оценку от одной до пяти. После выбора появятся поля для имени и текста отзыва. Заполни их и нажми «Отправить».

Добавленный отзыв сразу появится в списке и сохранится в `localStorage`.

## Где лежат данные

- Фильмы и их описания: `src/data/movies.json`.
- Локальные постеры: `public/posters/`.
- Вопросы и логика подбора по настроению: `src/data/moodQuiz.ts`.
- Скрипт массового добавления фильмов, постеров и Rutube-ссылок: `scripts/add-movies.mjs`.

Если нужно добавить фильмы вручную, добавь новый объект в `movies.json` и положи соответствующий постер в `public/posters/`. В поле `poster` должен быть локальный путь вида `/posters/example.jpg`.

## Структура интерфейса

Основные экраны и компоненты разделены между собой:

- `HomePage` — главный экран и подборки.
- `CatalogPage` — каталог, поиск, фильтры и сортировка.
- `GenrePage` — страницы отдельных жанров.
- `MoodQuizPage` — тест подбора фильма по настроению.
- `SavedPage` — сохранённые фильмы.
- `MovieModal` — подробности фильма, просмотр позже, оценки и отзывы.
- `GlassHeader` — общая шапка сайта и переключатель темы.

## Важные команды

```bash
npm run dev
npm run lint
npm run build
npm run preview
```

`npm run dev` нужен для разработки. `npm run lint` проверяет код. `npm run build` собирает проект для production. `npm run preview` запускает локальный просмотр production-сборки.
